# PRINTCALC FLEXO V4

Быстрый менеджерский калькулятор для рулонной флексопечати.

## Основные возможности

- быстрый расчёт тиража;
- расчёт метража;
- расчёт материала;
- расчёт краски;
- расчёт времени производства;
- расчёт себестоимости;
- предварительная цена клиенту;
- ручьи;
- технологический запас;
- красочность;
- ламинация;
- вырубка / резка;
- история расчётов;
- локальное сохранение;
- поддержка Supabase при наличии существующей конфигурации.

## Назначение

PRINTCALC рассчитан прежде всего на менеджера типографии,
которому нужно быстро получить ориентировочную стоимость заказа,
не проходя через сложный технологический интерфейс.
